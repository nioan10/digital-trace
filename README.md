# Цифровой след

Учебное расследование инцидента информационной безопасности — дело «Север».

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются.

В практикуме: восемь материалов дела, проверка версий, восстановление хронологии, выбор действий и тест из 16 вопросов. Результат можно скачать текстовым файлом. Ответы хранятся в памяти вкладки; обновление страницы начинает новую попытку.

## Публикация

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root), затем Save. Сайт доступен после успешной публикации GitHub Pages.

Компания, персонажи и события вымышлены. Проверка учебная; серверная верификация личности и ответов не предусмотрена.


Дополнительный сценарий «Один рабочий день»: почтовый ящик, три решения с последствиями и заключение по журналу выбранного пути. Сценарий отделён от учебного дела с фиксированными материалами. Ход расследования можно скачать. Данные остаются в текущей вкладке; перезагрузка начинает новую попытку.

## Практикумы по модулям

`practice.html` — отдельная учебная мастерская: шесть модулей по три ситуации. Форматы: выбор фрагментов, проверка писем, переключатели защиты, исключение данных из запроса, порядок действий и классификация доказательств. После каждого решения доступны объяснение и повтор. Баллы, ФИО, выгрузка и серверное сохранение не используются. Отметки о завершённых модулях хранятся только в памяти текущей страницы.
