# Цифровой след

Учебное расследование инцидента информационной безопасности — дело «Север».

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются.

В практикуме: восемь материалов дела, проверка версий, восстановление хронологии, выбор действий и тест из 16 вопросов. Результат можно скачать текстовым файлом. Ответы хранятся в памяти вкладки; обновление страницы начинает новую попытку.

## Публикация

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root), затем Save. Сайт доступен после успешной публикации GitHub Pages.

Компания, персонажи и события вымышлены. Проверка учебная; серверная верификация личности и ответов не предусмотрена.
